# 📱 Android Core Concepts

Hi! 👋

Welcome to my Android learning repository.

This repository contains the code I wrote while learning Android development with **Java** and **Android Studio**. Before moving to Flutter, I spent time understanding how native Android apps work by practicing the core concepts and building small examples.

Instead of only watching tutorials, I learned by writing code, testing different ideas, and solving problems along the way. This repository is a collection of that practice, and I'll continue updating it whenever I learn something new.

If you're also starting your Android development journey, I hope these examples make learning a little easier.

## 🚀 Getting Started

1. Clone the repository

```bash

```

2. Open the project in Android Studio.

3. Build and run the project on an Android device or emulator.
